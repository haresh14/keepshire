2. PURPOSE AND AUDIENCE
Keepshire is a private, encrypted vault for photos, videos, audio, and documents that people want to keep off their camera roll: ID scans, receipts, medical paperwork, personal photos. It is for adults who share or hand over their phone and want some files behind a separate passcode. Everything stays on the device: no account, no cloud, no analytics. Files are encrypted with AES-GCM using a key derived from the user's passcode or password.

3. HOW TO REVIEW (no login or demo account needed)
- First launch: choose "6-digit passcode" (any code, entered twice). Face ID is optional.
- The empty vault shows "Add Files" / "Add Photos". Later, use the "…" button at the top right → Add Files. Pick photos from the system photo picker (no photo-library permission is requested) or any file from the Files app. Any photo on the review device works; no sample files are required.
- Tap an item to open it: pinch to zoom, double-tap, swipe between photos. Videos play inline; PDFs and documents open in the viewer.
- Folder tab: create folders and move files. Category tab: browse by type. Gallery: all photos and videos.
- Share sheet: in Photos or Files, share an item to "Keepshire"; it is imported the next time the vault is unlocked.
- Settings: auto-lock timing, Face ID, change passcode, a decoy passcode that opens an empty vault, screenshot blanking, shake/flip to lock, and Trash.
- Web Upload (optional): tap Start Server, open the shown https:// address in a browser on another device on the same Wi-Fi, accept the browser's certificate warning (the certificate is generated on the phone), and enter the 6-digit pairing code. Local Network permission is requested only then. Downloads also require Face ID or the vault passcode.
- If you forget the review passcode, delete and reinstall the app to start a new, empty vault.

4. EXTERNAL SERVICES
None. Keepshire uses no third-party SDKs, analytics, advertising, authentication, payment, AI, or cloud services and makes no network requests to any server. It uses only Apple frameworks (SwiftUI, CryptoKit, CommonCrypto, Security, Network, PhotosUI, AVKit, PDFKit, QuickLook, LocalAuthentication). The optional Web Upload server runs on the phone itself and is reachable only on the local Wi-Fi. The privacy policy and support pages are static web pages.

5. REGIONAL DIFFERENCES
None. The app works the same in every region; the interface is English.

6. REGULATED INDUSTRY / THIRD-PARTY MATERIAL
Not applicable. Keepshire is not in a regulated industry and contains no third-party content. It only stores files the user adds.

ENCRYPTION DETAILS
Files and metadata are encrypted on device with AES-GCM (CryptoKit); the key is derived from the vault passcode with PBKDF2-HMAC-SHA256 (CommonCrypto); Keychain items are ThisDeviceOnly; vault files are excluded from backup. Web Upload uses HTTPS (Network framework) with a new self-signed certificate per session. Screenshot blanking uses a standard secure text field layer and does not block the screenshot itself.
